# 预测目标变量定义 · targets.md

> 任务书 §4：没有标签就没有校准。本文件**写死**系统预测什么、三档研判如何对应概率。  
> 校准完成前，所有阈值标记为 **初始猜测值**；页面必须显著标注「系统未校准」。

---

## 1. 空间与时间窗

| 项 | 定义 |
|---|---|
| 关注区域 | 上海市行政范围；潮位另含黄浦江代表站（吴淞、黄浦公园，以可得实测为准） |
| 事件窗 | 以「台风编号过程」为主键：自系统首次研判 ≥ 关注 起，至影响结束后 48 h |
| 预报时效 | 决策层按 D-7…D-0；评分按起报时刻相对影响中心日的 lead time 分箱 |
| 标签来源优先级 | ① 上海市气象局公开预警记录 ② 市防汛/教育部门停课停工通告 ③ 水文潮位公报 ④ 事后整编雨量 |

---

## 2. 主目标（Primary）

### Y_main：是否发布「台风或暴雨橙色及以上」预警（二分类）

| 项 | 定义 |
|---|---|
| 正类 (1) | 事件窗内，上海市气象局曾发布 **台风橙色/红色** 或 **暴雨橙色/红色** 中至少一种 |
| 负类 (0) | 事件窗内未发布上述等级（含仅蓝/黄，或无预警） |
| 粒度 | 每个「台风过程 × 上海」一条标签 |
| 备注 | **不是**预测国家级路径是否登陆；是预测**本地法定高影响预警是否触发** |

> 系统内部研判用语为「关注 / 警戒 / 行动」，**禁止**使用蓝黄橙红预警色名与配色。  
> 主目标用「橙色及以上」仅作为**标签定义**，引用官方预警记录时除外。

---

## 3. 辅助目标

### Y_rain：全市面雨量过程累计是否超阈（二分类）

| 项 | 定义 |
|---|---|
| 指标 | 事件窗内上海全市面雨量过程累计 R（mm） |
| 正类 | R ≥ **R0** |
| R0 初始猜测 | **100 mm**（过程累计；未校准） |
| 数据 | 市气象/水文整编；缺失则该过程此辅目标标为 NA，不参与校准 |

### Y_disrupt：是否出现停工停课或大型活动普遍取消（二分类）

| 项 | 定义 |
|---|---|
| 正类 | 事件窗内出现：全市或多数区 **停课** / **停工** 通告，或本单位同类大型活动 **普遍取消**（需人工或通告库标注） |
| 负类 | 无上述措施 |
| 备注 | 标签噪声大；Layer B 前仅作辅助，不单独驱动状态灯 |

### Y_tide：黄浦江潮位是否超警戒（二分类）

| 项 | 定义 |
|---|---|
| 指标 | 代表站最高潮位 H_max |
| 正类 | H_max ≥ 该站 **警戒潮位**（以水务/防汛现行值为准，写入配置） |
| 初始 | 具体警戒高程写入 `config/thresholds.yaml`，标记 `status: initial_guess` |

## 4. 研判等级与概率区间

系统输出四态：**无影响 / 关注 / 警戒 / 行动**。  
底层对主目标估计 **p = P(Y_main=1 | 当前多源信息)**，再映射到等级。

### 4.1 概率 → 等级（初始，未校准）

| 等级 | 概率区间（初始猜测） | 决策含义（单位活动） |
|---|---|---|
| 无影响 | p &lt; 0.10 | 正常排期 |
| 关注 | 0.10 ≤ p &lt; 0.35 | 扫描活动，标记风险场次 |
| 警戒 | 0.35 ≤ p &lt; 0.65 | 备选方案成型，准备对外口径 |
| 行动 | p ≥ 0.65 | 预备/正式决策窗口（对齐 D-2/D-1） |

> 以上切点 **全部为初始猜测**，须在 `backtest.md` 用混淆矩阵与代价敏感点重标定。  
> 在样本量 &lt; 任务书要求（约数十例上海影响台风）前，UI 固定文案：  
> **「未校准 · 概率切点为初始猜测 · 仅供内部参考」**。

### 4.2 等级与辅目标的一致性格（非硬约束）

| 等级 | 与辅目标的期望关系（描述性） |
|---|---|
| 关注 | Y_rain / Y_tide 多为 0；Y_disrupt 极少为 1 |
| 警戒 | Y_rain 或 Y_tide 之一接近阈；Y_disrupt 开始出现 |
| 行动 | Y_main=1 高概率；常伴 Y_disrupt=1 或 Y_tide=1 |

不一致时（例如高 p 但辅目标全 0）在影响层展示「情景冲突」，**不**自动降级主灯（避免用未校准辅目标覆盖主目标）。

## 5. 与 Layer A / B 的关系

| 层 | 如何产生 p |
|---|---|
| **A（当前）** | 规则 + 集合特征（DCA、强度、风圈覆盖、象限、移速、大潮叠合、离散度等）打分后经 **未校准** sigmoid/分段映射到 p；等权多源 |
| **B** | 用存档预报 vs Y_* 估计各源误差与偏差；性能加权；重新标定 p→等级切点 |
| **C** | 可选 AI 模式作为额外成员，不单独定义新标签 |

## 6. 评分指标（回算用，写入 backtest.md）

主目标：

- Brier score  
- 可靠度图（reliability diagram）  
- 混淆矩阵 @ 三档切点  
- 代价敏感：漏报「行动」权重高于空报（具体比写入配置，初始 3:1）

路径（辅助，非本系统核心 KPI）：

- 各时效大圆距离误差分布（仅对参与回算且有 a-deck 的源）

离散度：

- 集合离散度 vs 实际路径误差相关；**未完成映射前禁止单独展示「确定性分数」**
